So I have now been amost 100 % relying on LLM to generate my codes for the past few months. But there are still some really nasty problems I've been meeting using the latset publicly available LLMs and I really don't think these should really been a problem these day. I mean, given the fact that the LLMs are already solving millennium prize problems. I often find these thing quite ironic and can't stop to question if these are some intrinsic limitations in the transformer architecture. I am listing here some of the most annoying problems, for fun and for record. After all, I bet it would be really fun looking backs at these words in 10 years.


## LLM can't understand the username is part of a host

So in my daily work. SSH to a remote server and do some work is a very common thing. And nowadays I am handing off the stuff to the LLMs. But ever so often, I find it tends to get stuck in SSH work mysteriously. And after some time. I will see that it's attempting to install some python env for me. It turns out to be very stupid. It never ssh to the server with the username I gave it! As a result. It's in my local user name and It of cause can't accomplish what it's asked to do. It then will try to "iron it out" on its own by pulling dependencies. The end result of this is: 1. millions of tokens wasted; 2. half an hour has passed by before you realize something really is not going on correctly and the worst: Your remote server's environment might have been cooked.
